# Publication Hypotheses

**Protocol version:** 1.0  
**Frozen:** 2026-08-29  
**Status:** FROZEN unless revised through the decision log

## H1 — Configuration Effect

Holding management composition constant, different spatial and temporal
configurations of irrigation regimes may generate different peak
irrigation demand.

## H2 — Peak Versus Seasonal Effect

Configuration effects are expected to be more pronounced for peak and
temporal irrigation demand than for total seasonal diversion.

## H3 — Hydrological Mechanism

Any configuration effect should be interpretable through physically or
operationally meaningful mechanisms, including:

- canal-network position;
- turnout grouping;
- groundwater conditions;
- soil and hydraulic properties;
- drainage and return-flow pathways;
- temporal synchronization.

Pure geometric proximity is not sufficient evidence of mechanism.

## H4 — Uncertainty Requirement

A configuration effect will be considered scientifically meaningful only
if it exceeds the combined relevant uncertainty arising from:

- observations;
- parameters;
- model structure;
- model implementation.

## Null Hypothesis

After management composition, weather and hydrological conditions are
controlled, spatial placement and temporal synchronization have no
practically meaningful independent effect on the principal hydrological
endpoint.

A robust null result is an acceptable scientific outcome.

## Important Constraint

Management composition must remain constant during the configuration
experiment.

For example, if the baseline composition is:

- 30% WFL;
- 40% DFL;
- 30% safe AWD;

then all configuration scenarios must preserve those proportions.

Changing management proportions changes composition and therefore does
not provide a clean test of configuration.
