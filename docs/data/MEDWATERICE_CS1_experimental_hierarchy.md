## Required Verification

Before statistical analysis determine:

- number of physical pilot fields;
- number of plots within each field;
- whether treatments were replicated;
- whether sensors are nested within fields;
- whether measurements are repeated through time;
- whether the same locations were reused across years;
- treatment allocation method;
- presence or absence of randomization;
- exact irrigation-management definition in each year.

## Statistical Rule

Temporal measurements, sensors and pixels must not be treated as
independent experimental replicates.

The true experimental unit must be established from the experimental
layout and metadata before inferential statistics are used.
